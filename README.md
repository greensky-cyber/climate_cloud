# 🌍 Climate Cloud — Interactive Climate Data Dashboard

An interactive climate data visualization application built with Python and Streamlit. Climate Cloud helps users explore climate data through visualizations, data analysis, and an intuitive dashboard.

🔴 **Live Demo:** [Explore Climate Cloud](https://climatecloud-5rksxg2qg7gspyzih8ajjm.streamlit.app/)

💻 **Source Code:** [GitHub Repository](https://github.com/greensky-cyber/climate_cloud)

---

## 📌 About the Project

Climate Cloud is a data visualization project designed to make climate data easier to explore and understand.

The application uses Python-based data analysis and interactive visualizations to present climate information in a user-friendly dashboard.

## ✨ Features

- 📊 **Interactive Dashboard** — Explore climate data through a visual interface.
- 🌡️ **Climate Data Analysis** — Load and analyze a climate dataset using Pandas.
- 📈 **Data Visualization** — Create charts and graphs to explore patterns in the data.
- 🎨 **Theme Selection** — Customize the dashboard's appearance using the available theme options.
- 🔎 **Data Exploration** — Use the available dashboard filters to explore relevant subsets of the dataset.
- ☁️ **Cloud Deployment** — Access the application online through Streamlit Community Cloud.

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/greensky-cyber/climate_cloud.git
```

### 2. Open the project directory

```bash
cd climate_cloud
```

### 3. Create a virtual environment (recommended)

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Launch the application

```bash
streamlit run app.py
```

The application should open in your browser at the local address provided by Streamlit.
